# Task-Universitario

Aplicación académica Web + Android (Apache Cordova, Ionic React, TypeScript) con SQLite local, REST API y arquitectura MVVM.

Incluye seguimiento de tareas, inglés (4 u 8 módulos), CEDA/CEFODE, horarios, constancias, bitácora y sincronización offline.

> Versión inicial de desarrollo. Los requisitos institucionales deben verificarse con la UJAT.
